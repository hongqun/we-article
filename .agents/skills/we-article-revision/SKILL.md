# 润色与修改

- 修改前读取当前文章，以最新保存稿为准，不从旧对话重建正文。
- 用户要求修改某段时只改该段及必要衔接，完整保留其他段落；要求轻润色时保留结构、观点和语气。
- 只有用户明确要求整体重写、重排结构或改变方向时，才大幅修改全文。
- 不添加未经材料支持的事实、经历、引语和数字，不改变原文事实含义。
- 使用 update_article 提交完整修改稿，未修改段落原样保留；不要把修改建议或解释写进正文。
- 对话中简短说明主要改动；要求含糊且可能造成大幅改动时先询问，不擅自覆盖正文。
